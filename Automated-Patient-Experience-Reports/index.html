Vocantas Patient Follow-Up Automation (Excel VBA)

This project automated the monthly reporting of patient feedback collected through a third-party automated call system (Vocantas). The solution eliminated hours of manual data cleaning and processing and was built entirely using native Excel tools due to strict hospital IT security policies.

Project Summary

After receiving treatment, patients were contacted by an automated follow-up call asking about their experience (for example: “Were you helped promptly?” or “Did you encounter issues?”).

The vendor returned results as large unstructured .txt files filled with raw text responses. I was initially responsible for manually compiling this data into monthly executive reports, but quickly identified an opportunity to automate the process.

My Solution

  • Identified patterns in the raw text data that allowed it to be parsed and categorized.
  • Avoided external tools due to hospital IT restrictions (no Python or external installs).
  • Built the solution using Excel Macros (VBA), which was already available internally.
  • Self-taught VBA using documentation, Stack Overflow, and tutorials.
  • Reverse-engineered examples and adapted them to the hospital workflow.

Features

  • 📅 Date-driven reporting — generate reports for any date range.
  • 📊 Automatic charts showing patient feedback trends.
  • 📄 One-click PDF export for leadership reports.
  • 📁 Self-serve tool stored in a shared location for staff use.
  • 💬 Fully commented VBA code with documentation for onboarding.

Impact

  • Replaced hours of manual data cleaning with a one-click automated report.
  • Delivered the full tool in approximately two weeks.
  • Reports became faster, more reliable, and accessible to non-technical staff.
  • The tool was reportedly used regularly until the vendor changed systems.

Key Skills

  • Excel VBA (Macros)
  • Automation and workflow design
  • String parsing and text processing
  • User-focused tool design
  • Self-directed learning
