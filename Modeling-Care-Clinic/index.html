Palliative Care Clinic Simulation (Simul8)

This project models and simulates a palliative care outpatient clinic using Simul8 to evaluate how the clinic could handle projected increases in patient volume while operating with limited resources.

Project Context

With a rising number of patients expected to attend the outpatient clinic through referrals and chemotherapy pathways, the team needed to determine whether the current staffing and workflow could support the increased demand.

To address this, I built a discrete-event simulation using Simul8 that models the full patient journey — from intake and triage through physician consultation and discharge or return visits.

Objectives

  • Simulate patient flow across a palliative outpatient clinic
  • Model resource constraints including nurses, physicians, and secretaries
  • Evaluate the clinic’s ability to handle projected patient increases
  • Identify potential workflow improvements
  • Implement loops for returning patients during the year

Methodology

Real-World Shadowing

  • Shadowed nurses and secretaries to understand daily workflows
  • Designed a Microsoft Form to track nurse activities and identify bottlenecks
  • Aligned the simulation schedule with real clinic operations
  • Collaborated with staff to validate simulation assumptions

Simulation Features

  • Patient entry via referral or chemotherapy clinic pathways
  • Nurse triage followed by physician consultation
  • Discharge or return loop for follow-up visits
  • Custom Simul8 Visual Logic macros for routing and decision logic
  • Annual simulation run cycle to forecast resource utilization

Workflow Improvements

  • Provided technical coaching to clinical staff on digital workflows
  • Improved operational efficiency through staff feedback integration
  • Adjusted simulation logic to better reflect real patient care pathways

Software Setup

  • Advocated for a Simul8 upgrade when existing version was insufficient
  • Negotiated a $1000 price reduction with the vendor
  • Arranged on-site support for deployment
  • Handled installation and environment setup for the team

Learning & Development

  • Attended Simul8 webinars to learn Visual Logic scripting
  • Built custom routines for patients returning within a year
  • Implemented cyclical patient loops between nurse and physician visits
  • Defined simulation endpoints such as discharge, death, or year rollover
